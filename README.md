# Heart Disease KNN Classifier

A simple and lightweight implementation of a **K-Nearest Neighbors (KNN)** classifier for predicting heart disease based on clinical measurements.  
This project demonstrates a clean, modular workflow for data preprocessing, analysis, and distance-based classification without relying on scikit-learn’s built-in KNN.

---

## 🚀 Features

- Custom implementation of the **KNN algorithm**
- Support for **mixed numeric and categorical features**
- Modular preprocessing pipeline:
  - Missing value imputation
  - Min–Max scaling
  - Train–test split
- Standalone utility functions for reuse
- Jupyter Notebook for interactive exploration
- Clean code structure following best practices

---

## 🛠 Installation

Clone the repository:

```bash
git clone https://github.com/mahmoud-sadrian/heart-disease_KNN_classifier.git
```

Install dependencies:
```bash
pip install -r requirements.txt
```
or manually:
```bash
pip install numpy pandas matplotlib seaborn
```
