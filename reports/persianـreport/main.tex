	\begin{abstract}
		این گزارش یک مطالعهٔ داده‌کاوی بر روی مجموعه‌دادهٔ بیماری قلبی از مخزن UCI است و هدف آن پیش‌بینی وجود بیماری قلبی بر اساس ویژگی‌های بالینی بیماران با استفاده از الگوریتم KNN می‌باشد. داده‌ها پیش‌پردازش شده‌اند (جایگزینی مقادیر گمشده، نرمال‌سازی و تقسیم آموزش–آزمون) و تحلیل اکتشافی داده‌ها (EDA) شامل هیستوگرام‌ها، نمودارهای جعبه‌ای، نمودارهای احتمال–احتمال، ماتریس همبستگی، نمودارهای چندمتغیره (Pair Plot) و نمودارهای شمارشی انجام شده است. طبقه‌بند KNN با استفاده از تابع فاصلهٔ ترکیبی پیاده‌سازی شده و عملکرد آن با معیارهایی مانند دقت، بازخوانی، دقت مثبت، امتیاز F1 و ماتریس اغتشاش ارزیابی گردیده است.
	\end{abstract}
